Why Spidey?

Everything you need.
Nothing you don't.

Built for modern Ruby projects with clean architecture, sensible defaults, and a powerful DSL.

⚡

Elegant DSL

Define crawlers with intuitive crawl and process blocks. Readable and maintainable by design.

🔄

Auto Retry

Configurable retry logic with exponential backoff. Your crawlers survive network blips gracefully.

🚀

ActiveJob Ready

Drop-in support for Rails ActiveJob. Each page request becomes a background job automatically.

🎯

Nokogiri Powered

Every response is a full Nokogiri document. Use .css(), .xpath(), and .links() out of the box.

⚙️

Rate Limiting

Be a good citizen. Configure requests per second to avoid hammering servers.

🧬

Inheritance

Build base crawlers with shared config. Subclass and extend with custom behaviour per site.

Quick Start

Up and crawling
in minutes.

bash 
# Add to your Gemfile
gem 'spidey'

# Or install directly
gem install spidey
ruby 
require 'spidey'

class HackerNewsCrawler
  include Spidey

  crawl "https://news.ycombinator.com/" do |response|
    response.css('a.titlelink').each do |a|
      process! a['href'], :story
    end
  end

  process :story do |response|
    puts "#{response.uri} — #{response.title}"
    save_story(response)
  end

  private

  def save_story(response)
    # Your persistence logic here
  end
end

# Fire it up!
HackerNewsCrawler.crawl!
ruby 
class ProductCrawler < ApplicationJob
  queue_as :crawlers

  include Spidey

  crawl "https://shop.example.com/products" do |response|
    response.css('a.product-link').each do |a|
      process! response.resolve(a['href']), :product
    end
  end

  process :product do |response|
    Product.create!(
      url:   response.uri.to_s,
      title: response.css('h1').first&.text,
      price: response.css('.price').first&.text
    )
  end
end

# Enqueue all crawlers
ProductCrawler.crawl!
ruby 
Spidey.configure do |config|
  # Custom logger
  config.logger = Logger.new("log/spidey.log", level: :debug)

  # Requests per second (rate limiting)
  config.rate_limit = 2

  # HTTP timeout in seconds
  config.request_timeout = 15

  # Auto-retry failed requests
  config.max_retries  = 3
  config.retry_delay  = 1.0   # exponential backoff

  # Custom headers sent with every request
  config.default_headers = {
    "User-Agent" => "MyBot/1.0 (contact@example.com)"
  }
end

API Reference

Module Methods

  • Spidey.configure { |c| } — Block-style configuration
  • Spidey.run — Run all registered crawlers
  • Spidey.list — Array of all crawler classes
  • Spidey.find("name") — Find a crawler by name

Class DSL

  • .crawl(url) { |r| } — Register start URLs
  • .process(:type) { |r| } — Named processors
  • .crawl! — Kick off crawling

Instance Methods

  • #process!(url, type) — Process a URL
  • #perform(url, type) — Synchronous request+handle
  • #crawl! — Run all start URLs

Response Object

  • .css(selector) — Nokogiri CSS query
  • .links(selector?) — Extract all URLs
  • .title — Page title string
  • .resolve(href) — Absolute URL resolution
  • .success? / .error? — Status helpers

Configuration Keys

  • logger — Ruby Logger instance
  • request_timeout — Seconds (default: 30)
  • max_retries — Retry count (default: 3)
  • rate_limit — Req/s (default: nil)
  • follow_redirects — Bool (default: true)
  • default_headers — Hash of headers

Rake Tasks

  • rake spidey:run — Run all crawlers
  • rake spidey:run[name] — Run specific crawler
  • rake spidey:list — List crawlers
  • rake spidey:debug[name,url] — Debug single URL
